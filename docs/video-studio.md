# 本机视频工作室

在任意文章顶部操作栏点击场记板按钮（`视频工作室 / Video Studio`），即可在当前文章页面直接弹出沉浸式浮窗，保持原有阅读上下文与滚动位置。浮窗首次打开时会结合当前文章章节与 `Video-Generator` 模板自动生成逐镜口播文案与动态分镜初稿；用户可在浮窗内直接修改口播词、切换风格包、实时预演并合成最终视频。

## 启动

首次准备媒体运行时：

```sh
node scripts/setup-video-studio.mjs
```

依赖安装到 `~/.local/share/knowledge-hub-video-studio/runtime`，仓库目录保持纯净，GitHub Pages 静态发布流程保持不变。当前媒体实现针对 Apple Silicon macOS、已安装的 Google Chrome、macOS 本机声音，以及已配置的本地 Z-Image-Turbo。

然后启动或重启本机站点：

```sh
node scripts/serve-knowledge-hub.mjs
```

打开 `http://127.0.0.1:8000/` 并进入任意文章，点击文章顶部「视频工作室」按钮即可呼出页内浮窗。端口冲突时设置 `KH_PORT`。即便在纯静态托管页面打开浮窗，也能基于当前文章 DOM 自动生成口播与动态分镜预演；点击语音合成或 MP4 导出时则会展示本机服务启动说明。

## 四步向导与零配置一键出片

### 单行高密度专业顶栏与快捷胶囊条

界面采用非线性剪辑工作台（NLE）布局，拒绝在画布上方叠加多层通知横幅与重复工具栏。顶部仅保留唯一一条 48px 高密度专业顶栏：

- **左侧**：工作台标题与当前文章简短标题（超长自动省略）。
- **正中**：32px 紧凑型胶囊步骤指示器（`[✓ 1.脚本] ➔ [✓ 2.画面] ➔ [○ 3.配音 0/6] ➔ [○ 4.成片]`），垂直零额外行占用，悬停可检视各阶段详情。
- **右侧**：Copilot 连接与模型选择、视图聚焦切换组（`[◧ 左栏]`、`[◨ 右栏]`、`[⬓ 时间轴]`、`[⛶ 沉浸预览]` 一键收起或展开辅助面板），以及主行动按钮「⚡ 一键生成视频」。生成进行中时，该按钮直接转化为带百分比填充动画的胶囊进度条（`⏳ 生成中 18% · 点击取消`），顶栏底边同步亮起 2px 流光进度线；整片合成完毕后直接显现「⬇ 下载 MP4」入口。

顶栏下方紧贴一条 38px 快捷胶囊条（Studio Quick Bar，在沉浸预览模式下自动收起），集中承载 4 种视觉风格（🏛️ 专业 / ✨ 活泼 / ⚡ 动态 / 🌿 优雅）、动态背景音乐开关与 4 种代码合成配乐风格（知性科技 / 轻快律动 / 动感节奏 / 优雅极简）、口播或演示模式及目标时长（60s / 180s）胶囊开关。重生成分镜、批量素材维护、导出工程清单、创作方案与作业记录等低频操作全部收纳至右侧「⋯ 更多」弹出菜单，平时完全隐身，把 60% 以上的屏幕面积留给中央 16:9 画面监看器。

### 四大流体渐变与生命感视觉风格、代码动态合成 BGM

每一帧 1920×1080 视频画布均由同构渲染引擎（`assets/video-studio-composition.js` 的 `drawAmbientEnvironment`）按时间戳 `t` 实时绘制多层动态渐变与有机生命感图形：

- **🏛️ 专业（`professional`）**：深邃蓝灰/暖米平滑渐变网格底 + 呼吸感精密坐标网格线与几何光点脉冲（默认绑定 `01-A` 色板）；
- **✨ 活泼（`vibrant`）**：明快珊瑚橙/青柠流体渐变 + 漂浮跃动的圆润光斑气泡与弹性卡片（默认绑定 `05-A` 色板）；
- **⚡ 动态（`dynamic`）**：深空霓虹渐变底 + 实时流动的能量光线轨迹与底部时间驱动律动声谱条（默认绑定 `04-A` 色板）；
- **🌿 优雅（`elegant`）**：暖金与暮光紫丝绸径向渐变 + 缓慢呼吸的萤火焦外光斑（默认绑定 `01-D` 色板）。

背景音乐由 `assets/video-studio-bgm.js` 与 `scripts/video-studio-bgm.mjs` 在代码中实时合成 48kHz 双声道立体声波形，支持 `ambient-tech`（知性科技 · 96 BPM）、`upbeat-pulse`（轻快律动 · 112 BPM）、`dynamic-drive`（动感节奏 · 122 BPM）、`elegant-minimal`（优雅极简 · 78 BPM）及 `none`（纯人声无配乐）。浏览器预演开启配乐时由 WebAudio 实时合成循环播放，整片混音（`scripts/video-studio-audio.mjs` 的 `assembleAudio`）内置前瞻包络检测（Sidechain Ducking），在人声口播区间自动平滑压低配乐音量至约 16%，停顿处柔和回升。

### 智能体创作，而非套版

首先填写“你的创意想法”：想讲什么故事、给谁看、希望产生什么感受，以及不希望出现什么。需求模板只是可编辑的起点，不绑定任何画面版式。Copilot在同一创作任务中承担导演、编剧和摄影指导的职责，输出可查看的创作方案、旁白、叙事意图、摄影设计，以及可执行的逐镜头编排。角色名称不是额外审批环节，也不是三个各自运行的后台智能体。

新版画面不再强制使用左侧标题卡、顶部标签、底部字幕条或统一插画前缀。智能体决定图像裁切与焦点、文字位置和层级、图形关系、配色以及图层运动的时机；文字可以留空，纯文字和图解镜头不需要生图。图层是执行绘制的基本能力，不是可选版式列表。浏览器预演与Motion Canvas出帧共用同一绘制逻辑；文字超出图层高度会明确报错，不偷偷截断。

表达方式先于素材选择：智能体先判断观众需要理解的关系、过程或变化，再选择文字、图形、运动、运镜或必要的图像。不要求每镜生图，也不要求按固定比例混合媒体。四个需求预设只描述受众与传播目标，不再默认插画、拼贴或人物故事；用户已保存的风格不会被自动覆盖。

原生绘制支持文字、基本形状、矢量路径、图层组合和整体运镜。路径可逐步描绘，组合内对象可独立或整体运动，整体镜头可在信息空间中平移和变焦。它们不经文生图工具；只有编排明确使用图片（包括组合中的图片）时，才需要对应图像素材。纯图形镜头可以完全省略图片提示词。

正常使用按三个可见阶段进行：**生成分镜 → 生成素材并预演 → 制作视频**。主工具栏保留独立的素材生成按钮；尚未确认方案时显示“确认并生成素材”，已确认时显示“生成素材”，有未保存修改时显示“保存并生成素材”。它会确认当前分镜、按需生成图片和配音，然后停下来供试听与预演，不会开始视频渲染或导出；纯图形镜头不会生图。

已有素材时，主按钮显示“重新生成素材”（有编辑时为“保存并重新生成素材”）。点击后先确认替换，再真正重新执行所需图片和配音生成，不复用旧结果；取消不会保存草稿、确认方案或提交任务。图片生成使用新的生成版本和随机种子。配音会重新合成，但文字、声音和语速未变时，听感可能相同。

替换逐项提交：新文件生成、校验成功后才切换当前素材引用，失败或取消的项目保留原素材。已完成的新素材仍保留，旧文件不会被原地破坏。每项成功替换会使依赖它的视频片段和成片失效，需要主动重新制作；不会把旧视频显示为对应新素材的成片。替换操作本身不自动渲染或导出。

提交请求时立即显示等待进度，服务接受任务后持久化实际总数和0项完成状态；生成过程中显示当前镜头、素材类型、新生成和复用数量。完成的新素材会随进度轮询更新到工作台，不必等整批结束。百分比按已成功保存的项目数计算，不伪造耗时或单张图片内部进度。刷新恢复已保存的任务进度。

素材满意后点击“制作完整视频”，自动衔接片段渲染和整片导出。若不需要单独预览素材，也可直接制作，由系统补齐缺项，不要求重复操作。尚未确认方案时制作按钮显示“确认方案并制作视频”；有未保存修改时显示“保存并制作视频”。两个阶段都会先保存和确认当前方案，失败则明确提示，不继续生成。进度可查看、任务可取消，重复执行复用输入未变的结果。

希望修改视觉表达时，在镜头检视器展开“让AI调整画面”，描述修改意见并点击“按要求调整画面”。它是可选的方案编辑，不是制作前置步骤；保留旁白与已有素材，预演满意后仍点击同一个制作按钮。若想更换故事、人物、场景或整片艺术方向，应修改创意需求并重新生成分镜，而不是要求旧图片表现其本身没有的内容。

单独处理全片图片、全片配音、当前镜头素材以及手工确认方案等操作集中在检视器的“高级工具（通常无需使用）”，不再占据主工具栏。它们用于局部修补和排查，不是正常制作的必经步骤。高级工具关闭时，制作或素材维护的进度和停止按钮仍显示在主工具栏。

“重新生成”和“补齐”含义不同：主按钮用于确认后替换当前素材；高级工具中的“补齐全片素材／图片／配音”只处理缺项或输入变化，保留缓存复用。制作视频也默认复用当前有效素材，避免每次修改都重新生图和配音。

旧作业与缓存保留原样，刷新不会自动向Copilot发送请求。旧版提示旁提供可直接执行的“更新分镜设计”按钮，保留旁白与已有素材；若要重写故事，则使用上方“重新生成分镜”。成功前仍保留原版渲染方式，失败不替换现有内容。新版生成的镜头采用自由编排，版本指纹彼此区分。当前图像能力基于本地生成静态画面，摄影设计通过构图、裁切和图层动画呈现。配乐使用本机现有器乐合成实现。

设计和重设计不再沿用问答助手的115秒等待上限，每次允许最多8分钟，并显示实际已接收文字数，不伪造完成百分比。只有返回内容未通过编排接口检查时，智能体才会根据具体错误修订一次，可能额外消耗模型额度；网络、认证、额度或等待超时不会自动重试。修订后仍失败则明确报告，保留原稿，不把旧镜头冒充新设计。旧版作业会显示提示，便于区分“新功能可用”和“新设计已经成功应用”。

1. **需求确认**：可选择方案讲解（3分钟）、技术拆解（4分钟）、知识科普（3分钟）或短视频宣发（1分钟）模板，预填受众、目标、视觉方向、时长与配乐，也可自由填写。模板保留已选声音和语速；替换自定义需求前会确认，不自动保存或生成。保存并确认后才允许生成，重新打开会恢复保存的字段；字段仍匹配模板时显示对应选中状态。
2. **镜头工作台**：分镜文案、图片和配音合并为一个 Gallery。页面自动检测并复用已有 Copilot 登录，在右上角选择模型后主动生成分镜，不需要手动连接或重复勾选复选框；生成按钮旁保留文章全文与需求将发送至云端并可能消耗额度的说明。随后在同一镜头中审阅或编辑旁白、短句和画面，生成素材并试听预演，满意后制作视频。可点左右按钮、缩略图或使用左右方向键切换，切换不会丢失未保存的编辑；编辑框中的方向键仍用于编辑文字。仅图片、仅配音等单项维护操作仍放在高级工具中，不是前置步骤。
3. **镜头渲染**：素材齐备即可点击“渲染全部镜头”，无需逐镜头确认或逐个点击渲染。仅渲染缺失或变更的片段，其余复用缓存；显示真实进度，可取消，失败或中断后再次执行会复用已完成片段。也可单独渲染一个镜头。缺少当前版本的图片或配音时显示提示和返回工作台的入口。预览将片段画面与对应配音同步播放。
4. **整片导出**：所有镜头就绪后主动拼接。复制已有视频流，只重新混合配音和原创器乐，随后可预览、下载 MP4。

Gallery 提供**从当前镜头模拟播放**：使用已有图片、浏览器运镜与已生成配音连续预演，支持暂停、继续、停止，并自动切到下一个镜头。开启背景音乐时，预演会通过 WebAudio 实时合成并同步播放所选配乐（有配音时自动压低配乐增益，无配音时按估算时长伴随配乐或静音预演），不临时合成或朗读旁白，也不调用 Copilot、生图或视频渲染。若浏览器 `AudioContext` 恢复或配乐启动失败，错误会显式传播并停止预演提示用户。切换镜头、修改文案或离开工作台会停止预演，避免旧配音或配乐继续播放。

### 编辑工作区布局

四个流程共用同一个剪辑台，不再在表单页、镜头页和导出页之间切换布局。桌面窗口（宽度至少1100px、高度至少680px）采用全高无整体纵向滚轴的黄金三区分割：

- **左侧素材 / 镜头列表（宽 220px，支持点 `[◧ 左栏]` 收起为 0px）**：显示文章来源链接、干净清洗后的章节镜头标题及图片/配音就绪状态（提取时自动剔除 `#id`、`::versus` 等指令前缀与重复序号）。
- **中央监看器与极简播放控制条（`flex: 1` 自适应撑满）**：16:9 画布在 `1440×900` 视口默认编辑态下达到 `822×462px`，开启 `[⛶ 沉浸预览]` 后扩展至 `1319×742px`。画布正下方紧贴 40px 单行播放控制条（上一镜 / 播放预演 / 停止 / 进度条 / 时间码 / 全屏聚焦按钮）。
- **右侧属性检视器（宽 320px，支持点 `[◨ 右栏]` 收起为 0px）**：首屏直接舒展呈现高可读性的口播台词大编辑框（`min-height: 185px`）与 9 类 TPL 镜头编舞快捷切换胶囊；AI 画面微调与单项修补工具按需展开，面板内部独立滚动。
- **底部紧凑单轨时间轴（高 80px，支持点 `[⬓ 时间轴]` 收起为 0px）**：直观显示 V1 镜头时长比例、A1 配音就绪状态与实时播放头，点击任意片段即可跳转。

作业记录由工具栏按钮展开为侧边面板，关闭后不占据预览区域；Escape可关闭该面板。窄屏退回纵向布局，保持相同的确认、缓存和恢复机制。布局职责参考[DaVinci Resolve Edit官方说明](https://www.blackmagicdesign.com/products/davinciresolve/edit)中媒体池、Viewer和Timeline的分区，不宣称复制完整剪辑器功能。

当前序列支持选择与查看，不提供拖拽裁切、变速或波形编辑；排序仍使用属性面板的前移/后移。未生成配音的A1片段采用虚线和“估算”标签，不伪造音频波形或真实媒体时长。

原五步向导的已保存位置兼容保留：原“分镜与文案”和“素材确认”均映射到工作台，原片段预览和整片导出分别进入新第3、4步。作业、确认及缓存不迁移或重建。当前选中的镜头另按作业标识保存在本机浏览器，刷新后可回到同一镜头。

目标时长是编排参考，不会强行加快语音或剪掉旁白；导出前会显示实际片长。角色一致性、事实、构图、声音自然度与传播效果仍需用户审阅。新版镜头采用智能体设计的图层编排与关键帧，旧镜头兼容原有五类运镜；本机工具执行绘制与出帧，不执行模型生成的任意 JS。

批量任务在素材区顶部和作业记录中显示进度条、完成比例、当前镜头以及新生成/复用数量。百分比按实际完成素材数计算，图片与配音各计一项；单张图片生成期间不会虚增百分比或承诺剩余秒数。尚未取得总数时显示等待状态，失败、取消或服务中断会保留已完成的比例，刷新后从保存状态恢复显示。

## 持久化与恢复

作业保存在当前仓库的 `private/video-studio/`，该目录已被 Git 忽略。每篇文章有稳定作业标识，包含：

- 原文快照及指纹、需求、可编辑分镜、向导位置；
- 需求及分镜确认；旧版逐镜头素材确认记录兼容保留，但不再作为渲染或导出的门槛；
- 图片、配音、片段、导出文件及输入指纹、输出哈希；
- 每一步的排队、运行、完成、失败、取消或中断记录。

草稿使用原子文件替换和修订号检查，其他窗口的旧草稿不能直接覆盖新版本。刷新页面不重新生成；关闭页面不会取消本机正在运行的步骤。服务器异常退出后，旧运行记录会标为中断，用户主动继续，已完整保存的素材可复用。**这不是在 GPU 的某个采样步上断点续算**；未完成的工具调用可能需要重新执行，不承诺云端计费请求恰好执行一次。

必须点击“保存草稿”或“保存并确认需求”才持久化编辑；页面会提示未保存内容。文章内容变更后会提示来源过期，生成被阻止，需主动刷新来源并审阅，不自动改稿或重做影片。不要把本机私密目录纳入公开发布。

## 增量规则

| 修改 | 复用 | 需要更新 |
|---|---|---|
| 单镜头旁白、声音或语速 | 图片 | 该镜头配音、片段、最终导出 |
| 单镜头图片提示词 | 配音、其他镜头 | 该镜头图片、片段、最终导出 |
| 全局视觉方向 | 配音 | 所有受影响图片与片段 |
| 运镜、画面短句 | 图片、配音 | 该镜头片段与最终导出 |
| 镜头顺序 | 所有未变的镜头片段 | 分镜确认及最终拼接 |
| 配乐选项 | 全部图片、配音、片段 | 最终音频混合与拼接 |
| AI重新设计画面 / 图层文字与运动 | 原有图片、配音及叙事确认 | 受影响片段与最终导出 |

保存和模拟播放不触发以上更新，必须显式执行生成、渲染或制作。存在未保存编辑时会阻止预演和逐项工具操作；“保存并制作视频”会先保存当前编辑，再确认和制作，无需另点保存。当前图片与配音仍对应上次保存的版本。失效素材不会冒充已完成。旧内容仍在内容寻址缓存中，改回相同输入并主动执行时可再次命中。缓存损坏会明确报错，不用空图片或假成功继续。

## Copilot 与本机工具的边界

工作室沿用 [本机 Copilot 集成](copilot-provider.md)，通过官方 SDK/CLI 复用已有 `gh` 身份，不提取、复制或向浏览器发送凭证。右上角自动显示检测中、已连接、未登录或失败状态，并提供模型选择；点击状态可重新检测，无须重新填写需求。自动检测只读取官方登录状态及模型目录，不上传文章或提问；也不会自动开启新登录或切换账号。

模型选择保存在本机浏览器，重新打开后恢复；原模型不在目录时会提示重选，不静默改用其他模型。执行生成任务时禁止切换模型。登录有效不保证所有模型有推理权限或额度。Copilot 是云端推理，只有主动点击生成时，文章全文和需求才会发送到 GitHub 及模型服务。Studio不再使用发送前复选框；需求及分镜确认仍保留，图片与配音齐备后可直接渲染。文章问答助手的授权界面不变。

“生成分镜”是工具栏上的直接执行按钮，使用右上角已选模型，点击一次即提交生成，不展开面板或要求第二次点击。排队、生成期间显示“分镜生成中”并禁用重复提交；云端处理说明直接显示在按钮旁。

已审阅 CLI 1.0.83 / 1.0.105 / 1.0.114 的精确原生指纹及其随附 SDK 指纹。1.0.105 起已移除两个旧 remote 启动开关，按版本选择参数，保留每会话 `remoteSession: off`、空工具/MCP、关闭环境指令发现与权限拒绝。未知版本仍阻止执行，不自动升级。

Copilot 只返回经过结构校验的文字参数。本机服务仅按明确批准执行固定的生图、配音、渲染和拼接流程，不能由文章或模型传入可执行文件路径、shell 命令或任意代码。API 复用严格 loopback Host、同源 Origin、HttpOnly cookie 与 CSRF 检查。素材经认证 API 读取，不公开整个私密目录。
