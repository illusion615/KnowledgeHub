02 / Protocol

2. 固定协议把模型能力与测试过程分开

协议在正式运行前冻结；每轮创建全新 CLI 会话与隔离目录，关闭项目 custom instructions 和内置 MCP，不复用其他模型答案。

可执行正确性 · 25 分12 组隐藏断言检查数组、递归合并、不可变性、Date、null prototype 与 __proto__ 安全。
架构推理 · 20 分多租户实时协作系统，覆盖 CRDT/OT、1,000 并发、200 ms SLO、隔离、故障与权衡；三 judge 匿名评分。
长上下文 · 25 分阅读完整 4,489 行 runtime，提交恰好三个可复现 bug；误报直接失分，三 judge 对照源码验证。
长程执行 · 25 分实现无依赖任务调度器。10 组隐藏测试覆盖并发 claim、租约回收、退避、幂等、快照隔离与循环输入。
速度 · 5 分TTFT：model.call_start 到首 assistant/tool 事件；agent duration：用户消息到最后 assistant.turn_end。

07 / Evidence & Limits

7. 结果可复算，但不能替代更大样本

协议、prompt、fixture、隐藏 grader、脱敏 run 元数据、三 judge JSON 与聚合器均位于 tests/copilot-model-benchmark/。原始 CLI 事件不入库，以避免保存 prompt 和工具细节。

  1. 样本量：每模型两轮，只能识别明显波动；发布级结论应扩展到至少 5–10 轮。
  2. judge 分歧：Gemini 长上下文答案的单轮 judge 区间达到 9–25；中位数降低单点评分偏差，但不能消除主观性。
  3. 速度口径：agent duration 包含服务负载、模型调用、工具执行与修复，不是纯 token 生成速度。
  4. DeepSeek 缺席：当前账户/CLI 不提供该模型。获得 entitlement 后可用同一冻结协议补跑，不能用 fallback 结果补位。
  5. 版本边界：结果对应 Copilot CLI 1.0.80 和 2026-08-25 可用模型，后续模型更新需要重新执行。
