复数：从数系扩充到复平面运算

复数通过 i² = −1 扩充实数系，使每个实系数一元二次方程都能在复数范围讨论根。代数形式 a + bi 支持四则运算，复平面把实部与虚部分别映射到横纵坐标。

  • 2相等复数的实部、虚部分别相等
  • 3除法用分母共轭把分母实数化
  • 4几何问题把 z = a + bi 看作点 (a, b)

01 / 数系扩充

规定 i² = −1 后，负数开平方可统一写成实数倍 i

本节从方程 x² + 1 = 0 的实数无解出发，定义虚数单位、复数代数形式和复数相等；这些规则是后续运算的公理化起点。

任意复数写成 z = a + bi，其中 a 是实部、b 是虚部系数；实部与虚部的次序和角色不能交换。

01

实数是复数的子集

当 b = 0 时，a + 0i 就是实数 a；数系扩充保留原有实数运算。

02

纯虚数的实部为零

当 a = 0 且 b ≠ 0 时，z = bi 是纯虚数；i 本身对应 b = 1。

03

复数相等要求两个分量分别相等

该判据把复数方程转成两个实数方程。

由 i² = −1 可继续得到 i³ = −i、i⁴ = 1；之后每乘一个 i 重复同一四项周期。

指数除以 4 的余数幂值示例
01i²⁰ = 1
1ii²¹ = i
2−1i²² = −1
3−ii²³ = −i
易错边界√(−9) = 3i 描述主平方根；方程 x² = −9 的解则是 x = ±3i。根式值与方程的两个根不能混为一谈。

02 / 复平面与模

复数 a + bi 与平面点 (a, b) 一一对应

上一节把复数写成两个实分量，本节将它们映射到实轴与虚轴，并用距离解释复数的模和两复数之差。

z = a + bi 对应点 Z(a, b)，其模由勾股定理得到；两复数之差的模则是两对应点之间的距离。

代数解释

模是非负实数

|3 − 4i| = 5；模不是复数本身，也不保留方向。

几何解释

等模复数落在同一圆上

|z| = r 表示以原点为圆心、r 为半径的圆；r 必须非负。

z = a + bi 的共轭为 z̄ = a − bi；它保留实部、反转虚部，因此在复平面上关于实轴对称。

01

和提取实部

结果一定是实数。

02

差提取虚部系数

结果为纯虚数或零。

03

积等于模平方

该恒等式是复数除法实数化的核心。

03 / 复数四则运算

加减按分量，乘法用 i² = −1，除法乘分母共轭

复平面给出几何直觉，本节回到代数形式，建立四则运算的统一结果格式 a + bi。

把 i 当作符号参与分配律，最后用 i² = −1 降次，再合并实部与虚部。

运算公式结果类型
加法(a + bi) + (c + di) = (a + c) + (b + d)ia + bi
减法(a + bi) − (c + di) = (a − c) + (b − d)ia + bi
乘法(a + bi)(c + di) = (ac − bd) + (ad + bc)ia + bi

分母 z = c + di 非零时，同乘其共轭 c − di；分母变成 c² + d²，必为正实数。

  • 1
    写出分母共轭

    只改变虚部符号；c + di 的共轭是 c − di。

  • 2
    分子分母同乘

    同乘同一个非零复数不改变商值。

  • 3
    化为标准形式

    展开分子、用 i² = −1，再把实部与虚部分别除以实分母。

失败样例若 c = d = 0，原分母就是零复数，共轭法得到的分母仍为 0；复数除法与实数除法一样不能除以零。

04 / 方程与结构

复数相等与共轭根把复数问题转成实数方程组

四则运算得到标准形式后，本节用实部、虚部分离求参数，并说明实系数二次方程的非实根为何成共轭对。

含实参数 x、y 的复数等式先整理为 A(x, y) + B(x, y)i = 0，再令实部和虚部分别为零。

有效前提

参数声明为实数

只有 x、y 为实数时，x + yi 才直接把 x、y 解释为实部与虚部系数。

常见错误

只比较含 i 的项而忽略化简

表达式中若有 i²、分母或乘积，必须先完整化为 a + bi，再比较分量。

当判别式 Δ 小于 0 时，根式 √Δ 可写成 i√(−Δ)，求根公式给出两个虚部符号相反的根。

例如 x² − 2x + 5 = 0 的判别式为 −16，两个根为 1 ± 2i；根的和 2、积 5 仍满足韦达定理。

05 / 三角表示拓展

三角表示把复数写成模与辐角，乘除对应伸缩与旋转

2025 修订版把复数三角表示标为拓展内容；本节只建立代数表示与三角表示的转换及乘除几何意义，不进入复分析。

非零复数 z 对应从原点出发的向量；若其模为 r、与正实轴夹角为 θ，则可写成 r(cosθ + i sinθ)。

乘法

模相乘，辐角相加

几何上先按 r₂ 伸缩，再旋转 θ₂。

除法

模相除，辐角相减

要求除数模 r₂ 非零。

06 / 分层自测

六道题检验标准形式、复平面、除法与参数分离

前五节建立了代数与几何双重表示；本节按基础、综合和拓展三层检查能否正确化简并解释结果。

先按模 4 化简 i 的幂，再把结果整理为 a + bi。

  • 1
    化简 i⁵⁸

    58 除以 4 余 2，所以 i⁵⁸ = i² = −1。

  • 2
    计算 (1 + 2i)(3 − i)

    展开得 3 − i + 6i − 2i² = 5 + 5i。

三类任务分别调用距离、共轭与分量相等判据。

  • 3
    求 z = −5 + 12i 的模

    |z| = √(25 + 144) = 13；对应点到原点距离为 13。

  • 4
    计算 (2 + i)/(1 − i)

    同乘 1 + i，得 [(2 + i)(1 + i)]/2 = (1 + 3i)/2。

  • 5
    实数 x、y 满足 (x − 1) + (y + 2)i = 3 − 4i

    实部给 x − 1 = 3，虚部给 y + 2 = −4，所以 x = 4、y = −6。

乘以 i 不改变模，并把辐角增加 90°，因此在复平面上对应逆时针四分之一周旋转。

  • 6
    点 z = 2 + i 乘以 i 后的位置

    iz = 2i + i² = −1 + 2i，对应点从 (2, 1) 旋转到 (−1, 2)，两点到原点距离均为 √5。
