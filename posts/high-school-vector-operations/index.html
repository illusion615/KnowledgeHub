向量运算：加减、数乘、数量积与投影

向量同时携带大小与方向。高中运算包括加减、数乘和数量积；向量只能除以非零标量，本质是乘以其倒数，不存在通用的向量除以向量。

01 / 概念与表示

大小与方向共同确定向量，起点位置不改变自由向量

本节区分向量、标量、零向量与单位向量，并把几何箭头转换为坐标；这些定义决定后续每种运算的输入与输出。

向量用有向线段表示；只要大小相等且方向相同，即使画在不同位置也表示同一自由向量。

01

向量同时包含大小与方向

位移、速度和力是典型向量；只给数值而没有方向不能唯一描述它们。

02

标量只有数值大小

质量、时间和温度可用单个实数表示；标量可以缩放向量。

03

零向量没有确定方向

零向量坐标为 (0, 0)、模为 0；它不能被单位化，因为除数会变成 0。

04

单位向量只保留方向

非零向量 a 的同向单位向量为 a/|a|，其模等于 1。

若 A(x₁, y₁) 是起点、B(x₂, y₂) 是终点，则每个分量都用终点减起点；颠倒次序会得到相反向量。

从 A 到 B

终点减起点

A(−1, 2)、B(3, 5) 给出 AB = (4, 3)，模为 5。

从 B 到 A

方向反转，分量同时变号

BA = (−4, −3) = −AB；两者模相同、方向相反。

02 / 加减与数乘

加减组合位移，数乘改变长度并可能反转方向

上一节确定了向量的大小与方向，本节建立三角形法则、平行四边形法则和数乘规则，并明确向量除法的边界。

把第二个向量的起点平移到第一个向量终点，首尾连接后的合向量从最初起点指向最终终点。

  • 1
    三角形法则处理连续位移

    若 AB = a、BC = b，则 AC = a + b。

  • 2
    平行四边形法则处理共同起点

    以 a、b 为邻边，公共起点出发的对角线表示 a + b。

  • 3
    减法转成加相反向量

    a − b = a + (−b)；从共同起点看，a − b 指向从 b 的终点到 a 的终点。

实数 λ 乘向量 a 会把模放大为 |λ||a|；λ 的正负决定方向保持还是反转。除以非零标量等于乘其倒数。

01

λ 大于 0 时方向保持

λ = 2 使长度加倍；λ = 1/2 使长度减半。

02

λ 小于 0 时方向反转

−a 与 a 等长反向；−3a 还会把长度放大三倍。

03

除以模得到单位向量

当 a ≠ 0 时，e = a/|a| 与 a 同向且 |e| = 1。

运算边界高中向量体系没有通用的 a/b。只有 a 除以非零实数 λ 被定义；数量积 a·b 是乘法形式，但结果是实数，也不能作为向量除法的逆运算。

03 / 基与坐标表示

平面内两个不共线向量可唯一表示任意向量

加减和数乘建立了线性运算，本节用平面向量基本定理把几何对象编码为坐标，并给出共线、模与单位化判据。

若 e₁、e₂ 不共线，则平面内任意向量 a 都能且只能写成 λe₁ + μe₂；唯一性使坐标运算可靠。

04 / 数量积与投影

数量积把方向关系转化为一个可计算实数

坐标表示让线性运算可计算，本节进一步用数量积连接夹角、垂直、功和投影；这是 2025 修订版明确要求的投影内容。

对非零向量 a、b，数量积等于两向量模与夹角余弦的乘积；在直角坐标系中等于对应分量乘积之和。

01

数量积为正表示锐角

a·b > 0 时 cosθ > 0，因此 0° ≤ θ < 90°。

02

数量积为零判定垂直

对两个非零向量，a·b = 0 当且仅当 a ⟂ b。零向量与任意向量数量积也为 0，但没有方向。

03

数量积为负表示钝角

a·b < 0 时 cosθ < 0，因此 90° < θ ≤ 180°。

a 在非零向量 b 方向上的数量投影是带符号长度，投影向量则把该长度乘以 b 的单位向量。

  • 1
    选择投影方向

    分母和最终方向都由 b 决定；把 a、b 颠倒会得到不同问题。

  • 2
    计算平行分量

    proj_b a 与 b 共线，其系数正负表示同向或反向。

  • 3
    剩余量是垂直分量

    a − proj_b a 与 b 的数量积为 0。

失败样例当 b = 0 时，|b| 与 |b|² 都为 0，投影公式无定义；零向量没有可作为投影目标的方向。

05 / 几何与物理应用

共线、垂直、夹角与功可由同一套向量运算解决

数量积已经编码方向关系，本节把坐标判据用于平面几何、力学和解三角形，并比较何时选综合几何或向量法。

先把几何条件翻译成方向向量或位移向量，再按共线、垂直或夹角选择公式。

问题判据边界
平行或三点共线a = λb 或 x₁y₂ − x₂y₁ = 0方向判定通常要求非零向量
垂直a·b = 0两方向向量均非零
夹角cosθ = (a·b)/(|a||b|)0° ≤ θ ≤ 180°
恒力做功W = F·s = |F||s|cosθF 为恒力、s 为位移

三角形边向量满足首尾相加关系，数量积展开 |a − b|² 可得到余弦定理；正弦定理则用于已知一组对边与对角时求解。

余弦定理

适合边边边或边角边

本质是两个边向量之差的模平方。

正弦定理

适合已知对边与对角

边边角情形需检查可能存在两个三角形。

06 / 分层自测

六道题检验线性运算、数量积、投影与应用

前五节已经建立运算与判定体系；本节按基础、综合和应用三层检查结果类型、零向量边界与公式选择。

先判断结果应为向量还是实数，再逐分量计算。

  • 1
    a = (2, −1)、b = (−3, 4)，求 2a − b

    2a − b = (4, −2) − (−3, 4) = (7, −6)。

  • 2
    求 v = (−3, 4) 的同向单位向量

    |v| = 5，所以 v/|v| = (−3/5, 4/5)。

数量积负责方向判定，投影还要明确目标方向向量。

  • 3
    求 m，使 (m, 2) 与 (1, −3) 垂直

    m × 1 + 2 × (−3) = 0，所以 m = 6。

  • 4
    求 a = (3, 4) 在 b = (1, 0) 方向上的投影向量

    a·b = 3、|b|² = 1，所以 proj_b a = 3b = (3, 0)；剩余 (0, 4) 与 b 垂直。

应用题把物理量或几何关系翻译成向量后，仍回到数量积与线性组合。

  • 5
    10 N 恒力与 6 m 位移夹角 60°，求功

    W = 10 × 6 × cos60° = 30 J。只有沿位移方向的力分量做功。

  • 6
    A(0, 0)、B(4, 1)、C(1, m)，若 AB ⟂ AC，求 m

    AB = (4, 1)、AC = (1, m)，数量积 4 + m = 0，所以 m = −4。
