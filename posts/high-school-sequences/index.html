01 / 数列知识地图

数列是定义域为正整数集或其有限子集的函数

本节先固定数列的函数身份、四种表示和三个核心量；这些概念决定后续公式中的下标、项数与累计边界。

数列记作 {aₙ}，其中 aₙ 是位置 n 对应的函数值，Sₙ 是从第 1 项累加到第 n 项的总和。

01

通项公式定位单项

给定 n 可以直接求第 n 项，也可以由已知项反求 n。

02

递推公式连接相邻状态

递推必须同时给出初始项，否则不能唯一确定整个数列。

03

前 n 项和描述累计

当 n ≥ 2 时有 a_n = S_n − S_{n−1}，但首项应单独取 a_1 = S_1。

同一数列可以在列表、离散图象、通项公式与递推公式之间转换；选择标准是当前问题需要看到哪种结构。

表示突出信息限制
列表前若干项的具体数值不能证明规律对所有 n 成立
离散图象增减、增长速度与上下界点之间没有连续函数值
通项公式任意一项与下标的直接关系不一定容易从题目直接得到
递推公式当前状态如何生成下一状态求远处项通常需要逐步计算

02 / 等差数列

相邻项保持固定差时，通项呈一次函数式增长

上一节建立了通项与累计量，本节把固定增量翻译成公差 d，并推导第 n 项与前 n 项和。

若对所有适用的 n 都有 aₙ₊₁ − aₙ = d，则每前进一步增加同一个 d；从首项走 n − 1 步即可到达 aₙ。

已知首项

从 a₁ 向前走 n − 1 步

例如 a₁ = 4、d = 3，则 a₈ = 4 + 7 × 3 = 25。

已知任意一项

任意两项之差等于下标差乘公差

该形式减少先求首项的中间步骤。

等差数列首尾两项、第二项与倒数第二项的和都等于 a₁ + a_n，因此总和等于项数乘首尾平均值。

  • 1
    确认项数

    从第 p 项加到第 q 项共有 q − p + 1 项，不是 q − p 项。

  • 2
    选择已知量更完整的公式

    已知首末项用 n(a₁ + a_n)/2；已知首项和公差用第二式。

  • 3
    检查结果量级

    和应等于项数乘平均项；若明显超出该量级，应检查项数或下标。

03 / 等比数列

相邻项保持固定非零比时，通项呈指数函数式变化

等差数列使用固定增量，本节改用固定倍率 q；这会把线性增长转换为指数增长、衰减或交替变化。

若非零项之间始终满足 aₙ₊₁/aₙ = q，则从首项到第 n 项共乘 q 达 n − 1 次。

01

q 大于 1 时绝对值通常增长

正首项对应指数增长，例如复利、人口按固定比例增长。

02

q 位于 0 与 1 之间时衰减

每一步保留固定比例，例如折旧、药物浓度或放射性衰变的离散模型。

03

q 小于 0 时符号交替

绝对值由 |q| 决定，正负号随奇偶位置交替；判断单调性时不能只看 |q|。

把 S_n 乘 q 后与原式相减，中间 n − 1 项全部抵消；q = 1 时分母为零，必须单独处理。

失败样例 把 q = 1 代入分式会得到 0/0，而实际数列每项都等于 a₁，前 n 项和为 na₁。公式使用前必须先分情况。

04 / 题型与建模

识别差、比与累计结构，可把文字条件转成方程组

前两节给出了两个模型，本节按已知项、前 n 项和与现实递推三类输入组织统一解题流程。

无论是纯数学题还是贷款、折旧、增长题，都先定义第 n 项代表什么，再决定使用差、比、通项或累计公式。

  • 1
    定义对象与下标

    写清 a_n 是第 n 年末余额、第 n 层砖数还是第 n 次测量值；首项时刻必须明确。

  • 2
    识别固定差或固定比

    增加固定数量对应等差；按固定百分比变化对应等比。百分比需转为倍率 1 ± r。

  • 3
    建立最少未知量的方程

    优先使用 aₙ − aₘ = (n − m)d 或 aₙ/aₘ = qⁿ⁻ᵐ，避免无必要地先求首项。

  • 4
    核对整数性、单位与边界

    人数、层数和期数通常取正整数；金额、长度与比例需保留题目要求的单位和精度。

关系 a_n = S_n − S_{n−1} 只对 n ≥ 2 直接成立；第 1 项由 S_1 单独确定。

正确处理

先算 a₁，再写 n ≥ 2 的表达式

最后检查 n = 1 是否与后续表达式一致；不一致时保留分段形式。

常见错误

直接代 n = 1 并虚构 S₀

除非题目或定义明确给出 S₀ = 0，否则不能用未定义的 S₀ 替代首项检查。

05 / 数学归纳法

数学归纳法通过起点与递推步证明所有正整数情形

新版标准把数学归纳法标为拓展内容；本节只覆盖证明数列简单命题所需的基础结构，不扩展到强归纳法。

归纳法不是从若干样例猜结论，而是在验证起点后证明任一成立位置都能推出下一位置。

  • 1
    基础步

    验证命题 P(1) 或题目指定的最小下标成立。

  • 2
    归纳假设

    假设当 n = k 时 P(k) 成立；该假设必须在下一步中被实际使用。

  • 3
    归纳步

    从 P(k) 推出 P(k + 1)，而不是重新独立验证某个具体数字。

  • 4
    结论

    说明命题对从起点开始的所有正整数 n 成立。

06 / 分层自测

六道题检验通项、求和、建模与归纳结构

前五节已经形成完整方法链；本节按基础、综合和建模三层检查能否独立选择模型并验证结果。

两题分别检验等差通项和等比求和，先写模型参数再计算。

  • 1
    等差数列 5，8，11，… 的第 20 项

    a₁ = 5、d = 3，所以 a₂₀ = 5 + 19 × 3 = 62。

  • 2
    等比数列 3，6，12，… 的前 8 项和

    a₁ = 3、q = 2，所以 S₈ = 3(2⁸ − 1)/(2 − 1) = 765。

两题检验能否减少未知量，并正确处理 a₁ 与 n ≥ 2 的边界。

  • 3
    等差数列中 a₄ = 10、a₉ = 25，求 d 与 a₁

    5d = 15，得 d = 3；a₁ = a₄ − 3d = 1。

  • 4
    已知 S_n = n² + 2n，求 a_n

    a₁ = S₁ = 3；n ≥ 2 时 a_n = S_n − S_{n−1} = 2n + 1。该式代 n = 1 也得 3，所以统一为 a_n = 2n + 1。

应用题先定义时刻，证明题则检查归纳假设是否真正进入 k + 1 的推导。

  • 5
    设备初值 20,000 元，每年末保留 80%，三年末价值

    以初值为第 0 年，三年末为 20,000 × 0.8³ = 10,240 元。若把初值误作 a₁ 后代 a₃，会少乘一次。

  • 6
    用归纳法证明 1 + 3 + … + (2n − 1) = n²

    n = 1 成立；假设前 k 个奇数和为 k²，则再加 2k + 1 得 k² + 2k + 1 = (k + 1)²，因此对所有正整数 n 成立。
