圆锥曲线：从轨迹定义到方程与性质

01 / 三类曲线总览

距离和、距离差与等距条件分别生成三类圆锥曲线

本节先用定义、图形闭合性、标准参数和离心率建立对比地图；后续三节再分别推导公式与性质。

三类曲线都可写成点到焦点与准线距离之比为常数 e；e 的大小决定曲线闭合、分支或开口。

曲线轨迹定义参数关系离心率
椭圆到两焦点距离之和等于 2ac² = a² − b²0 < e = c/a < 1
双曲线到两焦点距离之差的绝对值等于 2ac² = a² + b²e = c/a > 1
抛物线到焦点与到准线距离相等焦准距由 p 决定e = 1

标准方程不是任意记号，而是把对称中心或顶点放在原点、对称轴放在坐标轴后的结果。

  • 1
    先找对称中心或顶点

    椭圆和双曲线以中心为原点；抛物线以顶点为原点。

  • 2
    让焦点或开口方向落在坐标轴

    焦点在 x 轴时，含 a² 的正项或一次项通常对应 x；焦点在 y 轴时对应 y。

  • 3
    再把距离定义平方化简

    平方前后要保留距离非负和定义中的常数边界，避免引入不符合原定义的点。

02 / 椭圆

椭圆以固定距离和形成闭合曲线，a 是半长轴

总览已经区分三类轨迹，本节从两焦点距离和等于 2a 出发，读取标准方程、焦点、顶点、范围与离心率。

椭圆中 a 始终大于 b；较大分母对应长轴和焦点方向，不能按字母 x、y 固定记忆。

焦点在 x 轴

焦点 (±c, 0)，顶点 (±a, 0)、(0, ±b)。

焦点在 y 轴

焦点 (0, ±c)，顶点 (0, ±a)、(±b, 0)。

标准椭圆关于两坐标轴和原点对称；x、y 的取值被半轴限制，因此图形闭合。

01

范围由半轴给出

横轴长轴时 |x| ≤ a、|y| ≤ b；纵轴长轴时相应交换。

02

离心率越小越接近圆

固定 a 时，c 变小意味着 b 变大；e 接近 0 时两半轴接近。

03

焦点距离和保持 2a

任一点 P 满足 PF₁ + PF₂ = 2a；该关系常用于求距离而无需先求坐标。

03 / 双曲线

双曲线以固定距离差形成两支曲线，正项决定实轴方向

椭圆依赖距离和且闭合，双曲线改用距离差的绝对值；本节重点区分正项方向、焦点关系和渐近线。

双曲线标准式中 a² 不一定是较大分母；a 对应实轴半长，c² = a² + b² 保证焦点比顶点离中心更远。

左右开口

顶点 (±a, 0)，焦点 (±c, 0)，渐近线 y = ±(b/a)x。

上下开口

顶点 (0, ±a)，焦点 (0, ±c)，渐近线 y = ±(a/b)x。

把标准式右边的 1 替换为 0，可因式分解得到两条渐近线；曲线无限接近它们但标准双曲线不与其相交。

  • 1
    确定正项方向

    正项是 x² 则左右开口，正项是 y² 则上下开口。

  • 2
    画辅助矩形

    以 (±a, ±b) 为角点，矩形对角线所在直线就是渐近线。

  • 3
    用顶点和渐近线定形

    两支从顶点向外延伸，并逐渐靠近对应渐近线。

常见错误椭圆用较大分母判断长轴，双曲线用正项判断实轴。把两条规则混用，会同时写错顶点、焦点和渐近线。

04 / 抛物线

抛物线由焦点与准线等距定义，p 的符号决定开口方向

双曲线有中心与两支，抛物线只有一个焦点和一条准线；本节用 p 统一四种朝向并读取焦点、准线和范围。

标准式中被平方的变量描述横截距离，一次项变量描述开口轴；p 是焦点到准线距离的一半并带方向符号。

方程开口焦点准线
y² = 2pxp 正向右，p 负向左(p/2, 0)x = −p/2
x² = 2pyp 正向上，p 负向下(0, p/2)y = −p/2

部分教材使用 y² = 4px 的记号，此时焦点写作 (p, 0)。两种约定都正确，但同一道题中必须保持一致。本文采用 y² = 2px。

抛物线上任一点 P 到焦点 F 的距离等于 P 到准线的垂直距离；面对距离问题时，定义往往比坐标开方更短。

01

顶点位于焦点与准线正中

标准式顶点为原点，焦点与准线分别位于开口轴两侧等距位置。

02

对称轴穿过顶点与焦点

y² = 2px 的对称轴是 x 轴；x² = 2py 的对称轴是 y 轴。

03

开口方向限制坐标范围

例如 p 正时 y² = 2px 必有 x ≥ 0，而 y 可以取任意实数。

05 / 直线与圆锥曲线

联立后的一元二次方程编码交点数量、坐标和弦长

三类标准方程已确定，本节把直线代入曲线，用判别式判断位置关系，并用韦达定理避免重复求根。

把直线方程代入圆锥曲线后得到 At² + Bt + C = 0；变量 t 可以是 x、y 或参数，判别式只判断实根数量。

判别式实根几何意义
Δ > 0两个不同实根直线与曲线有两个不同交点
Δ = 0一个二重实根通常表示相切；需确认代入未退化
Δ < 0无实根直线与实曲线无交点

若交点横坐标为 x₁、x₂，则无需写出根式即可得到 x₁ + x₂ 与 x₁x₂；中点、斜率积和弦长常因此简化。

  • 1
    检查二次项系数

    若 A = 0，方程退化为一次方程，不能继续使用二次判别式和两根韦达关系。

  • 2
    用 Δ 确认交点存在

    涉及弦长或两个交点时必须有 Δ > 0；不能只写韦达关系而忽略实根条件。

  • 3
    按目标选择根和、根积或根差

    根差平方可写成 (x₁ + x₂)² − 4x₁x₂，常用于弦长。

06 / 分层自测

六道题检验识别、参数、定义与直线联立

前五节已经完成从轨迹到交点的知识链；本节按基础、综合和联立三层检查能否独立选择公式并处理边界。

先判断曲线类型和朝向，再计算参数关系。

  • 1
    椭圆 x²/25 + y²/9 = 1 的焦点与离心率

    a = 5、b = 3、c = 4，焦点 (±4, 0)，e = 4/5。

  • 2
    双曲线 y²/16 − x²/9 = 1 的渐近线

    上下开口，a = 4、b = 3，渐近线 y = ±(4/3)x。

定义题优先使用距离常数，建方程题则先确定朝向和参数约定。

  • 3
    椭圆上点 P 到两焦点距离分别为 7 和 5，求 a

    PF₁ + PF₂ = 2a，所以 12 = 2a，得 a = 6。

  • 4
    焦点为 (2, 0)、准线 x = −2 的抛物线方程

    顶点为原点，本文约定 p/2 = 2，所以 p = 4，方程 y² = 8x。

联立前先确认代入后仍为二次方程，联立后再同时检查判别式和目标量。

  • 5
    直线 y = x + m 与抛物线 y² = 4x 相切，求 m

    代入得 (x + m)² = 4x，即 x² + (2m − 4)x + m² = 0。令 Δ = 0，得 (2m − 4)² − 4m² = 0，所以 m = 1。

  • 6
    直线 y = kx + 1 与椭圆 x²/4 + y² = 1 有两个交点时的必要检查

    代入形成关于 x 的二次方程；必须同时确认二次项系数非零且 Δ > 0。仅写根和、根积不能证明两个实交点存在。
