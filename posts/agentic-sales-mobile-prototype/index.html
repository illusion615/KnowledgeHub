① 工作台 · HomeDashboard + Code App Shell

主页从五屏入口升级为移动工作台

当前实现是 React + TypeScript + Vite 的 Power Apps Code App。主页仍保留 KPI、洞察、播报和快捷动作，但它现在连接账户、联系人、活动、商机、产品、设置和报表等完整业务面。

功能要点

KPI + 洞察 + 今日议程

  • 季度业绩、周动量、活动完成率从 Dataverse 聚合
  • 铃铛打开统一洞察 sheet，产品手册从主页直达
核心交互

ActionDock 承接页面动作

  • 主页注册新拜访、查看商机两个 dock chip
  • 移动端为浮层，宽屏可切左侧或右侧停靠
  • 下拉刷新和 sticky header 保持移动端操作连续
AI 角色

Frame · Plan · Execute 管线

  • Frame 阶段把一句话拆成多个 intent
  • Orchestrator 把 intent 变成 DAG 执行计划
  • Executor 调用查询、草稿、更新、知识等函数
数据与流

生成式 Dataverse 适配层

  • 账户、联系人、活动、商机、产品、设置均有 generated hooks
  • React Query 管理读取、创建、更新和缓存失效
  • Power Apps 宿主使用当前用户身份直连 Dataverse
路由 · /home Code App · React 18 Power Apps 1.1.3
② 播报与洞察 · BriefMe + Business Insights

播报从固定卡片升级为可生成的销售摘要

主页和 Brief Me 页复用系统语音、自动播报、语速和洞察数据。活动页另有周报视图，把日历和周进展放在同一条工作流里。

功能要点

播报、洞察、周报三类摘要

  • Brief Me 负责逐段语音播报
  • 统一洞察 sheet 汇总业务提醒
  • 活动周视图可切日历和周报
核心交互

听、停、跳转、追问

  • 语音引擎就绪前给出加载反馈
  • 系统音色由设置页统一选择
  • 洞察来源可跳账户、商机或活动页面
AI 角色

LLM 摘要 + 浏览器 TTS

  • generateVoiceSummary 可生成语音摘要、业绩分析和洞察文本
  • SpeechSynthesis 使用用户选择的系统音色
  • 自动播报可由设置开关控制
数据与流

Briefing / BusinessInsight / Activity

  • briefing、businessinsight、activity 均有 generated service
  • 周报从活动集合即时生成并按周缓存
  • 设置偏好本地化，Flow URL 等配置存 Dataverse Settings
路由 · /brief-me 活动页 · 周报 系统 TTS
③ 活动录入 · ActivityCapture + VisitLog

语音优先，文本和编辑能力保留

早期原型强调无键盘入口；当前代码已调整为语音优先而非语音唯一。活动录入支持编辑模式、活动详情回跳、客户上下文和确认后写库。

功能要点

活动类型、语音、字段草稿

  • activity-capture 支持新建与编辑两种路径
  • 活动详情页可回到同一 capture 表单继续修改
  • VisitLog 作为结构化拜访记录入口保留
核心交互

确认卡片优先于自由输入

  • 未解决的草稿、批量表单、匹配选择会锁定 composer
  • 用户必须先确认、修正或跳过阻塞卡片
  • 点击禁用输入框会定位到待处理卡片
AI 角色

visit-extraction + draft handlers

  • Frame 判断 Activity 的过去 / 未来时态
  • draft handlers 生成待确认写入卡
  • future activity 会进入日历可用性逻辑
数据与流

Activity native tables

  • appointment、phonecall、email 统一合并为活动列表
  • activity-service 和 validators 是生成代码
  • Activities 页提供周 / 月视图与下拉刷新
路由 · /activity/:accountId 路由 · /activities 写入前确认
④ 全局 Copilot · Panel + Conversation State

Copilot 从单页聊天升级为全局工作面板

当前实现通过 GlobalCopilot 注入所有页面，设置可控制全屏、浮层、左右停靠和是否全局显示。Copilot 面板支持附件、语音、TTS、页面上下文、Frame viewer、回滚和阻塞卡片。

功能要点

对话、卡片、附件、结果列表

  • DynamicDataRenderer 渲染结构化查询结果
  • FormCard、BatchFormCard、MatchSelectionCard 承担写入确认
  • MessageAttachments 支持图片与文件随消息发送
核心交互

浮层、全屏、左右停靠

  • 移动端强制浮层，宽屏按设置左 / 右停靠
  • 全局显示开启后采用折叠 dock 与全屏二态
  • 页面上下文 chip 可手动取消，避免错误复用
AI 角色

多意图 + 会话状态

  • ConversationState 维护 focus、workingSets、pendingGoal
  • contextSufficient 不再只靠裸对话文本判断
  • Frame viewer 和 benchmark ring buffer 用于检查管线
数据与流

CopilotConversation + Settings

  • CopilotConversation 记录消息与上下文边界
  • Flow URL、Copilot Studio agent 名称走 Settings 表
  • Copilot Studio 保留技能与 eval CSV 作为后端智能体设计
组件 · GlobalCopilot Frame viewer 附件 + TTS
⑤ 确认与详情 · Draft Review + Record Pages

人工确认成为所有写操作的产品边界

商机草稿仍是关键场景，但当前原型已经扩展到账户、联系人、产品、活动和商机详情页。写操作统一先出草稿或匹配选择，确认后再通过 generated service 写入 Dataverse。

功能要点

列表页 + 详情页 + 编辑页

  • accounts、contacts、opportunities、products 均有列表和详情路由
  • 详情页可跳相关联系人、商机和活动
  • 商机详情保留新增活动和编辑商机入口
核心交互

写入先确认，失败可解释

  • 创建、更新、删除动作均通过 handler 执行
  • 错误统一进入 AgentError 和 toast 反馈
  • retry 与 readback 测试覆盖写入可靠性
AI 角色

Copilot Studio 技能映射

  • log-sales-activity 负责拜访、电话、会议记录
  • manage-opportunity 负责商机创建与更新
  • query-and-report 负责列表、统计和状态报告
数据与流

DataImport 只保留为开发入口

  • /data-import 用于空 Dataverse 环境导入 UK seed data
  • 不接入主导航，不作为运行时业务入口
  • 导入后账户、联系人、商机、活动使用真实 Dataverse ID
路由 · /opp-draft/:activityId 路由 · /accounts /contacts /products Dev-only · /data-import
⑥ 客户列表 · Accounts

按联系新鲜度分级的客户列表

账户页顶部是覆盖统计，列表项用联系状态徽章（近期 / 活跃 / 降温 / 风险）标记新鲜度，点进即是账户详情页。

功能要点

统计卡 + 搜索 + 列表

  • 总客户、风险客户、本周已联系三项统计
  • 头像 + 名称 + 行业 + 联系状态徽章
核心交互

搜索过滤 + 点击进详情

  • 搜索框按名称即时过滤
  • 点击账户进 account-detail 概览/商机/活动三 tab
  • 下拉刷新重新聚合统计
AI 角色

客户画像与风险标记

  • 按 lastcontactedon 计算联系状态颜色
  • 超过阈值天数标记为风险客户
  • account-detail 提供可刷新 AI 总结卡
数据与流

account 标准表

  • 复用 Dataverse 标准 account 表
  • use-account hooks 提供列表与详情查询
  • 按 owner = 当前用户过滤
路由 · /accounts 联系状态徽章 详情三 tab
⑦ 商机管道 · Opportunities

阶段分布概览加单卡商机列表

管道页顶部用四段阶段分布（数量 + 金额），下方每张商机卡显示客户、金额、预计成交、阶段徽章和信心度。

功能要点

Pipeline 概览 + 商机卡

  • 四阶段分段显示数量与金额合计
  • 商机卡含阶段徽章 + 信心度 pill
核心交互

点击商机进详情

  • 商机详情含 4 段阶段进度条
  • 详情可跳客户、关联活动
  • 主页 KPI 卡点击直达管道页
AI 角色

信心度与趋势

  • confidence 0-100 驱动信心度 pill 颜色
  • confidenceTrend 给出升降箭头
  • manage-opportunity 技能负责创建与改阶段
数据与流

crf5c_opportunity1 自定义表

  • 阶段、金额、信心度、预计成交日为核心字段
  • use-opportunity hooks 管理读写
  • 账户通过 lookup 绑定
路由 · /opportunities 4 阶段进度 信心度 pill
⑧ 活动日历 · Activities

周月日历加按类型着色的活动列表

活动页支持周/月视图切换，日历格用活动类型彩点标记，下方活动卡按拜访/电话/会议着色，逾期项加红边。

功能要点

视图切换 + 日历 + 活动卡

  • 周 / 月视图切换，周视图可切日历与周报
  • 活动卡显示类型图标、客户、商机、时间
核心交互

选日期 + 进活动详情

  • 点日历格筛选当日活动
  • 逾期活动加红边并显示逾期天数
  • 活动详情可回 capture 表单继续编辑
AI 角色

周报生成

  • weekly-report 从本周活动生成 markdown 周报
  • 按周缓存避免重复生成
  • future 活动进入日历可用性检查
数据与流

appointment / phonecall / email

  • 三类原生活动表合并为统一列表
  • 活动类型颜色由 activity-colors 单一来源
  • statecode 区分已完成与计划中
路由 · /activities 周 / 月视图 活动类型着色
