① 主页大盘 · HomeDashboard

开机即得今日大盘

销售清晨打开 App 看到的第一屏：身份 + 4 张实时 KPI + AI 摘要 + Brief Me 入口 + 浮动 Copilot mic，全部从 Dataverse 实时计算。

功能要点

2×2 KPI + AI 摘要

  • 今日拜访 / 活跃商机 / 本月业绩 / 待跟进
  • AI 摘要按风险 · 商机 · 物流分色
核心交互

一屏三入口

  • Brief Me 卡 → 跳今日播报
  • 新拜访 chip → 跳语音录入
  • 底部 mic 按住 ≥ 300 ms → Copilot
AI 角色

3 个 Agent 协作

  • 指标分析 Agent · 算 KPI 与对比
  • 客户画像 Agent · 风险与机会
  • 订单查询 Agent · 物流与回款
数据与流

Account / Opportunity / Activity

  • 按 owner = 当前用户实时聚合
  • Brief Me 卡触发 Cloud Flow
  • 离线显示最近一次缓存
路由 · /home Fluent UI v9 双语 zh / en
② 今日播报 · BriefMe

6 章节 2 分 40 秒主动播报

通勤路上听一遍就知道今天该见谁、先打哪个电话。每章强制带 priority + 数字证据 + 今日就能做的 CTA。

功能要点

单卡承载完整章节

  • Headline + 证据摘要 + 2 条要点 + ≤4 metric
  • 加入今日 CTA · 一键拉到拜访列表
核心交互

听 + 切 + 追问

  • 左右滑动切章节 · dots 同步
  • 左 chip 切 1× / 1.5× / 2×
  • 底部 mic 长按 → 对当前章节追问
AI 角色

Briefing 编排 + TTS

  • Azure OpenAI 输出 6 章节 JSON
  • Azure Speech zh-CN-XiaoxiaoNeural 合成
  • 按风险 / 商机 / 顺路三类编排顺序
数据与流

Briefing 表 · Flow_DailyBriefing

  • 每日 06:00 定时触发 · 按销售生成
  • payload_json 存 6 章节 + audio_url
  • last_position 记忆上次播放位置
路由 · /brief Cron · 0 6 * * * ≤ 6 章节
③ 语音录入 · ActivityCapture

一段语音变三件事

按住 mic 说一段拜访总结，AI 自动产出拜访摘要 + 商机草稿 + 跟进动作；用户只做确认 / 编辑 / 重录三选一。点确认前不动 Dataverse。

功能要点

一屏完成录入

  • 语音气泡 · 实时转写
  • 拜访摘要 + 商机草稿双卡
  • ConfidenceBar 绿 / 琥珀 / 红
核心交互

确认 / 编辑 / 重录三选一

  • 确认 → 写 confirmed → 跳商机草稿
  • 编辑 → 字段内联修改
  • 重录 → 不动 Activity 行
AI 角色

转写 + 结构化抽取

  • Azure Speech 转写音频
  • Azure OpenAI 抽取 6 字段 JSON
  • confidence 0-100 写入 parsed_confidence
数据与流

Activity 表 · 草稿态

  • draft_status: draft → confirmed → discarded
  • Flow_VoiceToActivity (SharePoint 触发)
  • 离线本地 IndexedDB 缓存音频
路由 · /activity/:accountId ≤ 60 s 录音 Confirm 才写库
④ Copilot 问答 · CopilotChat

多 Agent 自动编排，不再翻菜单

销售只表达意图，Generative Orchestration 自动调用客户画像 + 商机评估等 Agent；每条 agent 答复独立显示并带来源 chip，绝不合并成一段散文。

功能要点

单列对话 · 三种消息类型

  • user · agent · stage-card
  • agent 名 pill 固定颜色
  • 来源 chip 点开看原始数据
核心交互

语音 / 文本 / 跳转

  • mic 按住 ≥ 300 ms 录音并发送
  • 长按 agent 消息 · 复制 / 转 Teams
  • stage-card 一键跳商机草稿
AI 角色

Copilot Studio Generative Orchestration

  • 客户画像 Agent · NPS / 互动
  • 商机评估 Agent · 阶段 / 信心
  • 订单查询 Agent · 物流 / 回款
数据与流

CopilotConversation 表

  • messages_json 持久化整段对话
  • AskCopilot Cloud Flow 编排多 agent
  • ERP 数据走 Dataverse Virtual Table
路由 · /copilot 流式打字 按 agent 拆分渲染
⑤ 商机草稿 · OpportunityDraftReview

字段可改 · 来源可追 · 异步回写 ERP

把 AI 推断的商机做最后一次人工把关：每个字段可内联编辑，每条来源可点开看原始证据；点提交即入队，写回 ERP 由 Flow 异步完成，UI 不阻塞。

功能要点

状态 · 字段 · 来源三段卡

  • 整体 ConfidenceBar · 待确认 badge
  • 6 字段 EditableRow + 修改痕迹橙点
  • 来源 chip · 可看录音 / 邮件原文
核心交互

提交即入队，不阻塞 UI

  • 确认创建 → 写 OppWriteQueue (pending)
  • Toast 已入队 · 回主页带状态条
  • 失败行点击重试 · last_error 可见
AI 角色

Activity → Opportunity 推断

  • 抽取产品 / 数量 / 金额 / 阶段 / 关闭日
  • 参考历史相似成交估算金额
  • confidence 上 ConfidenceBar
数据与流

OpportunityWriteQueue · ERP 同步

  • Flow_ActivityToOpportunity 生成草稿
  • Flow_OpportunityToERP 异步写回
  • 3 次重试 · 失败留 last_error
路由 · /opp-draft/:activityId 字段级编辑追踪 异步 ERP 回写
