Complete visual specification for the PptxGenJS export pipeline. Defines the slide grid system, typography token dictionary, color palette, and layout conventions with annotated example slides for every common layout type.

Export Pipeline

HTML article → Presentation steps → Native PPTX slides

  • 1enterPresentation() collects steps from hero + sections (accordion auto-split) + ending slide.
  • 2Pre-capture: SVG diagrams serialized to PNG data URLs via Canvas API.
  • 3forEach step: setPresentStep → renderStep dispatches to typed renderers (hero, table, flow, arch, insight, ending).
  • 4restoreSnapshot() exits fullscreen and returns to reading mode.

Three-tier hierarchy ensures component headings are always visually larger than body text:

T1

Slide Title — 28pt

Aptos Display bold. Anchor for the entire hierarchy. Hero H1 uses 36pt; ending slide uses 44pt.

T2

Component Heading — 20pt

Aptos Display bold. Flow step titles, card headings, accordion toggles. Insight cards use 16pt (smaller due to multi-column density).

T3

Body Text — 11-12pt

Aptos regular. Prose, descriptions, table cells. 12pt for standalone text; 11pt for dense contexts (insight cards, flow descriptions).

05 / Layout Conventions

PPT Export Layout Rules

Rules governing how HTML article content maps to native PptxGenJS slide objects.

Convention Rule
Slide masterCONTENT_MASTER: accent bar at y=0.30 (w=2.2 h=0.04), slide number top-right 9pt. Hero and ending slides use blank master.
Header areay=0.42 kicker (11pt bold alt) + y=0.72 title (28pt bold text). Body starts at BY=1.42.
Body areaBY=1.42 to BY+BH=7.0 (5.58 in). Width = BW = 11.893 in.
Vertical centeringAll non-overview slides: content measured by measureDispatch(). If content < body area, y += (BH − contentH) / 2.
Hero slideMeasure-first: compute left column + panel heights. startY = (SH − totalH) / 2. Metrics below tallest column.
Content sizingText boxes use estTextH(text, fontSize, width). No hardcoded heights. Tables 0.38 in rows, list items max(0.44, estimated).
Insight gridUp to 4 columns. Card height = max per row (content-driven). Same row shares height.
Arch diagrams.arch-layer: stacked colored roundRects. .arch-flow: horizontal block-arrow-block. Native shapes, never placeholder.
Flow listAccent circle 0.36 in (14pt white) + title 20pt bold + desc 11pt muted.
TablesaddTable() with equal columns. TH: 12pt bold alt 7% fill. TD: 12pt text. Row 0.38 in.
SVG diagramsPre-captured as PNG via Canvas API. Embedded as addImage({ data: dataUrl }). Aspect-ratio preserved, centered.
Ending slideCentered: accent bar + Thank You 44pt + QR code 1.8×1.8 in + scan tip 13pt + brand 11pt.
Overview slidesDescription at top (12pt). Accordion titles as collapsed rows (20pt, 0.46 in). No centering.
shrinkTextSafety net on all text boxes. estTextH() should prevent most shrinking.
FullscreenExport enters presentation mode, renders, then restores + exitFullscreen.
