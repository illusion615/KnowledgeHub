对数换底公式：把陌生底数化成可计算形式

换底公式把任意底数的对数转写为同一底数的比值。掌握定义域、推导和单调性后，它可以统一计算、化简、方程与不等式四类题。

01 / 定义域与意义

对数表示指数，三个定义域条件必须先于运算检查

本节先把对数还原为指数关系，并建立每道题都要执行的定义域检查；这组条件是下一节换底推导能够成立的前提。

等式 log_a N = x 的含义只有一个：底数 a 的 x 次幂等于 N。

指数视角

已知底数与指数，求幂值

例如 2³ = 8。指数式强调重复乘法产生的结果。

对数视角

已知底数与幂值，反求指数

同一事实写成 log₂8 = 3。对数是指数函数的反函数。

在实数范围内，底数和真数必须同时满足下表；方程求出的候选解还要回代这些条件。

条件 原因 典型后果
a > 0 实指数幂要求正底数才能构成连续指数函数 含参数底数时先解 a(x) > 0
a ≠ 1 1 的任意次幂都等于 1，不能唯一反求指数 底数含参数时排除使其等于 1 的值
N > 0 正底数的任意实数次幂始终为正 所有对数真数分别列出正值条件
边界判据 log₂(x − 3) 只在 x > 3 时有意义。代数变形得到 x = 3 或更小的值时，该值不是原方程的解。

02 / 换底公式推导

对等式两边取同底对数，可在四步内得到换底公式

上一节确定了合法底数与真数，本节把 log_a N 设为未知指数，再用一个任意合法新底数 c 消去原底数。

令 x = log_a N，把问题转成 a^x = N；随后对等式两边取以 c 为底的对数。

  1. 1
    设未知指数

    令 x = log_a N，根据定义得到 a^x = N。

  2. 2
    两边取同底对数

    选择 c > 0 且 c ≠ 1，得到 log_c(a^x) = log_c N。

  3. 3
    用幂的对数法则提取指数

    log_c(a^x) = x log_c a，因此 x log_c a = log_c N。

  4. 4
    解出 x 并还原

    x = log_c N / log_c a，再把 x 换回 log_a N。

把新底数分别选为 10、e 或另一个对数的底数，可以得到计算器形式、倒数关系与连乘关系。

01

计算器形式

常用对数 lg 与自然对数 ln 都可以作为统一新底数。

02

倒数关系

因为 log_a b = 1 / log_b a，交换底数与真数会取倒数。

03

连乘关系

中间底数 b 在换底后的分子与分母中约去。

03 / 对数运算体系

积、商、幂和换底分别处理四种不同结构

换底公式统一底数后，还要根据真数的乘积、商或幂结构选择对应法则；本节给出一张可直接查用的规则表。

对数法则只改变乘积、商、幂和底数，不能把真数中的加减法直接拆开。

结构 公式 使用前检查
真数为乘积 log_a(MN) = log_a M + log_a N M 与 N 分别为正
真数为商 log_a(M/N) = log_a M − log_a N M 与 N 分别为正
真数为幂 log_a(M^r) = r log_a M 在高中实数语境中先保证 M > 0
底数不同 log_a N = log_c N / log_c a a、c 为合法底数且 N > 0

每次变形前先指出当前处理的是积、商、幂还是底数，可以避免把形式相似误当作法则成立。

01

加法不可拆

log_a(M + N) 一般不等于 log_a M + log_a N；乘积法则只对应 MN。

02

换底分母是原底数

log_a N = log_c N / log_c a；分子保留原真数 N，分母放原底数 a。

03

不同底不能直接合并

log₂x + log₃x 不能直接写成一个对数；应先换成同一底数，再判断是否存在可用结构。

04

定义域不能在约分中消失

原式含 log_a(x − 1) 时始终保留 x > 1，即使后续代数式中 x − 1 被约去。

04 / 四类标准题型

同一条换底公式可贯穿数值计算、化简、方程与不等式

前两节给出了公式与规则，本节把它们转成四套固定流程；每套流程都从定义域检查开始。

计算 log₅36 时，分别取常用对数或自然对数会得到相同结果，因为新底数会在比值中消去。

  1. 1
    确认底数和真数合法

    5 > 0、5 ≠ 1、36 > 0。

  2. 2
    分子输入真数

    计算 lg36 或 ln36。

  3. 3
    分母输入原底数

    计算 lg5 或 ln5，再求比值。

式子 log₂3 · log₃5 · log₅8 的相邻底数与真数首尾衔接，换底后会连续约分。

识别信号 看到 log_a b · log_b c 时，优先使用连乘关系得到 log_a c；不必逐项近似计算。

方程 log₂(x − 1) + log₂(x − 3) = 3 的定义域是 x > 3；合并后得到一元二次方程，再排除不合法根。

  1. 1
    列定义域

    x − 1 > 0 且 x − 3 > 0，所以 x > 3。

  2. 2
    同底合并并指数化

    把对数和写成乘积的对数，再转成 (x − 1)(x − 3) = 2³。

  3. 3
    解代数方程并验根

    候选根为 5 和 −1；只有 5 满足 x > 3。

同底对数比较真数时，底数大于 1 保持不等号方向；底数位于 0 与 1 之间时反向。

a > 1

对数函数单调递增

仍需同时保证 M > 0 与 N > 0。

0 < a < 1

对数函数单调递减

去掉同底对数符号时，不等号方向必须改变。

05 / 分层自测

六道题覆盖换底、连乘、定义域与单调性

前四节已经形成固定流程；本节按基础、综合和参数三层检验能否独立完成每个步骤。

先独立计算两题，再用公式核对分子与分母的位置。

  1. 1
    把 log₇15 写成自然对数之比

    答案：ln15 / ln7。分子是真数 15，分母是原底数 7。

  2. 2
    化简 log₃5 · log₅3

    答案：1。两个对数互为倒数。

两题分别检验能否识别连乘结构，以及能否在解方程前保留定义域。

  1. 3
    化简 log₂3 · log₃7 · log₇16

    答案：log₂16 = 4。中间的 3 与 7 依次约去。

  2. 4
    解 log₃(x − 1) = 2

    定义域 x > 1；指数化得 x − 1 = 9，所以 x = 10，满足定义域。

参数题的首要任务是确定底数区间；只有区间明确后，才可以决定单调方向。

  1. 5
    log_(m−1)8 有意义时，m 满足什么条件

    底数 m − 1 > 0 且 m − 1 ≠ 1，所以 m > 1 且 m ≠ 2。真数 8 已为正。

  2. 6
    解 log_(1/2)(x + 1) > log_(1/2)3

    定义域 x > −1；底数 1/2 位于 0 与 1 之间，所以 x + 1 < 3，即 x < 2。合并得 −1 < x < 2。
