实时测试连接的是当前浏览器所在电脑的 http://127.0.0.1:8788。请在这台电脑启动 Python 代理，代理使用 Azure CLI 登录身份访问 Copilot Studio 与 Foundry。

  1. 准备运行环境与文件。安装 Python 3.10+ 和 Azure CLI，确认以下命令可用。后端使用 Python 标准库，无需 pip 安装依赖。 
    python3 --version
az version
    下载后端运行包，解压后进入 decision-arena-backend 文件夹。包内包含 arena_server.py、cs_benchmark_presets.py、arena.html 和 usage-audit/cs-real-benchmark-results.json，请保留目录结构。Windows 可将下方 python3 替换为 py -3。
  2. 确认云端配置与权限。默认配置连接本测试的 ZAF Prod 环境。使用自己的环境时，在 arena_server.py 中设置 DL_HOST、FOUNDRY_HOST、FOUNDRY_PATH、AGENT_SCHEMAS 和 DL_BOT_SCHEMA；对应环境应已发布 A/B/C/专项 Agent，B 的分类连接器和 C 的 Hook 工作流可用，Foundry Decision-1 部署可调用。登录账号需要这些 Agent 的调用权限和 Foundry 推理权限。
  3. 登录对应租户并启动。将租户占位符换为实际租户 ID。在解压目录执行： 
    az login --tenant <租户ID>
python3 arena_server.py
    保持终端运行，看到 Arena server listening on http://127.0.0.1:8788 后继续。启动会预热云端会话并调用 Decision-1，实时测试按实际资源用量计费。停止服务可在该终端按 Ctrl+C。
  4. 检查服务并重试。在另一个终端执行： 
    curl http://127.0.0.1:8788/api/health
    返回 JSON 中 "ok": true 表示本机代理正在运行。打开 本机测试台，点击“开启新会话”后重新发送；当前页面也可重试。完整云端权限与模型可用性以实际调用结果为准。

仍无法连接时：检查终端报错；端口占用时检查已有的 8788 服务；401/403 时重新登录正确租户并核对资源权限；网页被浏览器拦截本地网络访问时允许该权限，或直接使用上方本机测试台。切换设备或重启电脑后需在新设备重新启动代理。
